
# Predictive Analytics Using Historical Data (Power BI & Python — Week 3 Task)

An end-to-end Predictive Analytics and Time-Series Forecasting project that cleans historical revenue data, builds a Linear Regression forecasting model (`scikit-learn`), evaluates model accuracy ($R^2$ and RMSE), and visualizes 12-month future projections in Power BI.

---

## 📌 Features & Technical Workflow

- **Data Cleaning & Preprocessing:** Preprocessed 36 months of historical sales telemetry.
- **Predictive Regression Modeling:** Trained a Linear Regression model achieving $R^2 > 0.95$ for trend forecasting[cite: 25].
- **Future Forecasting Engine:** Predicted revenue trajectory for 12 future months[cite: 25].
- **Power BI Visualization:** Dual line series trend charts comparing actual vs. forecasted revenue streams[cite: 25].
